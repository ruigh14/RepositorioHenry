# Directivas (Capa 1)

SOPs en Markdown. Cada directiva describe una tarea y debe incluir:

- **Objetivo:** qué se quiere lograr.
- **Entradas:** datos/parámetros necesarios.
- **Herramientas:** scripts de `execution/` a usar y en qué orden.
- **Salidas:** qué se produce y dónde (intermedios en `.tmp/`).
- **Casos extremos y aprendizajes:** límites de API, errores conocidos, tiempos.

Nombre de archivo sugerido: `verbo_objeto.md` (ej. `scrape_website.md`).
No crees ni sobreescribas directivas sin consultar al usuario.
